# ⚡ JARVIS OMEGA // VEGA HUD

Local Offline AI Agent System with Three.js 3D WebGL Holographic HUD & Dual Voice Engine.

---

## 🚀 How to Run on Windows (NO DOCKER REQUIRED)

### Option 1: 1-Click Desktop Launcher (Recommended)
Simply double-click:
- **`JARVIS.exe`** OR
- **`START_JARVIS.bat`**

### Option 2: From PowerShell / Command Prompt
```powershell
cd C:\Users\HP\vega
py -3.11 app.py
```

Then open your browser at:
👉 **http://localhost:7860**

## 🌟 Key Features:
- **100% Offline Local Model:** Powered by Ollama (`llama3.2:1b`)
- **3D WebGL Holographic HUD:** Three.js animated interactive Arc Reactor
- **Dual Voice Link:** Real-time Speech-to-Text (Microphone) + Text-to-Speech (JARVIS Voice)
- **7 Specialist Agents:** Commander, Researcher, Executor, Guardian, Creative, Toolsmith, Monetizer
